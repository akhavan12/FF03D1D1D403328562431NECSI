# GitHub Pages Setup for NECSI Astro Site

Your site is ready to deploy to GitHub Pages! Here's how to set it up:

## 🚀 Quick Setup Steps

### 1. Enable GitHub Pages
1. Go to your repository: https://github.com/akhavan12/FF03D1D1D403328562431NECSI
2. Click **Settings** tab
3. Scroll down to **Pages** in the left sidebar
4. Under **Source**, select **GitHub Actions**
5. Save the settings

### 2. Push Your Code
```bash
# Add all files
git add .

# Commit changes
git commit -m "Deploy to GitHub Pages"

# Push to the astro-version branch
git push origin astro-version
```

### 3. Automatic Deployment
- The GitHub Actions workflow will automatically trigger
- It will build and deploy your site
- Check the **Actions** tab in your repository for deployment status

## 🐛 Troubleshooting

### If deployment fails:
1. Check the **Actions** tab for error logs
2. Ensure all files are committed and pushed
3. Verify the branch name is `astro-version`

### If pages don't load:
1. Wait a few minutes for GitHub Pages to update
2. Check that the base path is correct in `astro.config.mjs`
3. Clear browser cache and try again

### If assets don't load:
1. Ensure all images are in `public/assets/` folder
2. Check that image paths start with `/FF03D1D1D403328562431NECSI/`
